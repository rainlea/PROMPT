# 系统核验要点

以下只是检查路径，不新增采购要求；只核对当次招标明示或实现要求必然需要的条件。

| 系统 | 核验路径 |
|---|---|
| AV与显示 | 逐一枚举来源及显示目的端；同源、独立选源、同时输出分开；核对接口数量、分配转换、分辨率/帧率/色度、EDID及HDCP；同一输出不能凭空成为两路独立画面 |
| 平板展示 | 终端总数、在线数、并发展示数分开；四画面合成不等于四路独立输出；检查四路同时进入AV/处理器、合成同时进入AV/录播的复制与接口，授权及接收端资源 |
| 录播 | 来源逐路计数，资源流/节目流分开；核验所需分辨率是否可同时采集编码录制；单路4K不能证明多路4K；核对模式互斥、存储、码率、许可和下载；区分断外网与断局域网 |
| 摄像示教 | 原生输出、光学变焦、近摄/俯拍附件、控制协议、供电；机位用途与实际接入一致 |
| 音频 | 拾音→DSP→扩声/录播分支；接口类型/数量、独立增益和路由；功放输出模式、音箱阻抗与功率匹配；反馈风险需具体依据 |
| 中控 | 每个场景对应设备、协议、驱动、网关和许可；DALI、DMX512、RS485不能凭接口外形认定互通；停录保存及关机顺序 |
| UPS | 逐台累计保护负载W，分别检查VA/W限额及规定余量；续航依据准确UPS、电池和该负载曲线，不能由VA推出分钟；未知功率明示不确定性 |
| 工作站制作 | 操作系统/CPU架构、软件版本、采集设备、GPU/驱动及编解码兼容；硬编码不等于剪辑软件能调用；核对多路同时录制及素材进入剪辑导出的路径 |
| 软件 | 永久/订阅、本地/云端、授权设备数/并发数、维护到期行为；使用权与升级维护分开；不得假定未采购平台和服务器已存在 |
| LED | 大小屏分别查数量、尺寸、点间距、分辨率、控制器带载、功耗、附件和发布链路；合并计分不等于可漏查 |
| 布局 | 尺寸来源、设备数量、方向、通行和图纸要求；未有统一实测条件注明限制，不新增强电/承重/装修专项 |
